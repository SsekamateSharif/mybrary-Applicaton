
# Mybrary

## Description

Mybrary is a web application built using HTML, CSS, JavaScript, and EJS. The project focuses on creating a simple and user-friendly interface for a library-related website.

The application uses EJS (Embedded JavaScript) as its templating engine to dynamically render HTML pages on the server, allowing reusable components and dynamic content.

## Technologies Used

- HTML5 – For structuring the web pages.
- CSS3 – For styling and layout.
- JavaScript – For adding interactivity and functionality.
- EJS – For server-side HTML templating and dynamic page rendering.
- Node.js and Express.js – For running the server and handling application routes.
